# Contributing

Thank You for Your Interest into KryptonDOS! Your Contributions are very Welcomed and Appreciated.

## Getting Started

To Start Contributing, Please:
1. Fork this Repository
2. Create a New Branch for Your Changes `git checkout -b feature/your-feature`
3. Make and Test Your Changes
4. Commit Your Changes With a Clear Commit Message `git commit -m "Add your change"`
5. Push Your Branch `git push origin feature/your-feature`
6. Open a Pull Request

Before Opening your Pull Request Please Ensure That You Have:
1. Read This [Guide](CONTRIBUTING.md).
2. Check Existing Issues and Pull Requests to Avoid Duplicate Work.
3. Make Sure that Your Changes are in Alignment with this Project's Goals.
4. Tested Your Changes and Ensured that it is Stable and Working.
5. Ensured that Your Branch is Well-Organized and Clean

## Found an Issue?

If You Found a Bug or Have a Problem Please
- Check if the Issue Has Already Been Reported
- Open a Issue if it Hasn't
- Clearly Describe What Had Happened and How to Reproduce it
- Include Relavant Error Messages, Screenshots, Logs, or Other Useful Information

## Ooooh a New Feature?

When Requesting for a New Feature, Please Explain
- What You Desire to Add or Change
- Why this Feature would be Useful
- Any Implementation Ideas You Have.

## Questions?

If You are in Doubt, Feel Free to Open an Issue or Start a Discussion
